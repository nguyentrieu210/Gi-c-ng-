# Changelog

## [0.2.0] - 2026-09-12

### Added
- `MEMORY_CONTEXT.md` as a sanitized long-term context layer for the public repo.
- Career positioning across operations, production planning, farm/production management and ERP-style workflow thinking.
- Long-term project context for Alumdoor, agent orchestration, trading research and PWA/GitHub state.

### Changed
- `JOB_PIPELINE.md` now reflects the current career direction and offer review criteria.
- `README.md` now includes a repo map and public-memory boundary.

### Guardrail
- Public memory sync keeps useful decisions/patterns while excluding credentials, precise private data, health details and unnecessarily sensitive financial information.

## [0.1.0] - 2026-09-12

### Added
- Stable-life operating mode.
- Job pipeline without panic.
- Debt backlog policy.
- Family communication boundary.
- Decision log.

### Changed
- Success is no longer treated as an emergency.
- Failure to get a job immediately is no longer treated as system failure.

### Removed
- Forced life deadlines.
- Unnecessary proof to others.
- `force-push` behavior.
